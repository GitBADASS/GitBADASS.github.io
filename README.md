# 📔 Badass's Docs Site

> This docs site is hosted on GitHub, built with Docusaurus, dedicated to development documentation, technical sharing, creative works, and personal insights.

🌐 **Website:** https://badass.github.io/

This branch contains the source code of the site, while the [`deployment`](../../tree/deployment) branch contains the generated static site.

## 🌏 Languages

- English
- [简体中文](README.zh-CN.md)

## ☕️ Overview

This site is built with [Docusaurus](https://docusaurus.io/) and deployed on [GitHub Pages](https://docs.github.com/en/pages). It aims to **archive my development documentation and publish my blog posts.**

## 📚 Built With
