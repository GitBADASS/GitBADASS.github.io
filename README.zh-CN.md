# 📔 Badass 的文档网站

> 此网站托管于 GitHub，构建自 Docusaurus，主要用于存储**开发文档**，此外还分享**技术**与**创作**等方面的内容。

🌐 **网址：** https://badass.github.io/

此分支是源码分支，[`deployment`](../../tree/deployment) 分支则是构建完成的静态网站。

- English
- [简体中文](README.zh-CN.md)

## 🍵 概述

此网站基于 [Docusaurus](https://docusaurus.io/) 构建，并且部署于 [GitHub Pages](https://docs.github.com/en/pages)。它旨在 **存储开发文档和发布个人博客**。

## 📚 技术栈

- [Docusaurus](https://docusaurus.io/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [GitHub Pages](https://docs.github.com/en/pages)
